# Planetary Gearbox

A functional single-stage planetary gearbox designed and assembled in SolidWorks.

## Specifications

- Module: 2 mm
- Pressure angle: 20°
- Sun gear: 20 teeth
- Planet gears: 20 teeth
- Ring gear: 60 teeth
- Number of planets: 3
- Gear ratio: 4:1
- Input: Sun gear
- Output: Planet carrier
- Fixed member: Ring gear
